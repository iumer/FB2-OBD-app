# Car-uploaded drive logs

Finished FB2 Diag value-log sessions from the head unit land here as:

`FB2-log-yyyyMMdd-HHmmss.csv`

The app uploads **saved** sessions only (not the live buffer) when the HU
has internet and a GitHub token is configured in Settings → Log upload.

Browse files in this folder on GitHub to download a drive without emailing
yourself from the car.
